# Module F - CSV/TSV Editor cho WinUI 3 (.NET 8)
Hãy xây dựng Module F
## Mục tiêu
Tạo một module cho phép người dùng:
- Mở file CSV/TSV
- Hiển thị dữ liệu dạng bảng
- Chỉnh sửa trực tiếp
- Thêm/Xóa dòng
- Thêm/Xóa cột
- Đổi tên cột
- Tìm kiếm
- Lọc dữ liệu
- Sắp xếp
- Undo/Redo
- Lưu lại file
----------------------------------
UI
----------------------------------
Thiết kế giao diện WinUI 3 hiện đại.

[Statistics]
Bên dưới là DataGrid.
Yêu cầu:
- DataGrid tự sinh cột theo Header
- Cho phép chỉnh sửa trực tiếp từng ô
- Có Row Number
- Highlight ô đang sửa
- Cho phép chọn nhiều dòng
- Context Menu:
    Copy
    Paste
    Delete
    Insert Row
    Duplicate Row
